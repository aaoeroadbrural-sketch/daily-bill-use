# Daily Money Tracker

An offline Android personal finance app built with Kotlin, Jetpack Compose and Room.

## Features in this starter version
- Add income and expenses
- Date-wise transactions
- Automatic total income, spending and net balance
- Delete transactions
- Date-wise report
- Local offline database
- Indian Rupee formatting

## Build
Open the project in Android Studio (Ladybug or newer), allow Gradle sync, then Run on an Android device/emulator.

The project uses:
- Kotlin
- Jetpack Compose / Material 3
- Room database
- Android SDK 35
- Minimum Android 8.0 (API 26)
